# The Family Photo With One Machine Member — make.fun entry

A small Python program that draws a family at home with one machine member: a warm, flat-illustration living-room scene rendered entirely with Pillow (PIL). A dad relaxes on a mustard sofa with a mug, a mum holds a toddler, two kids play and reach out nearby, and a cream-and-teal domestic robot — mid-task, watering a plant with a tea towel over its arm — stands among them as part of the family, alongside a sleeping dog.

Bounty: https://make.fun/bounty/the-family-photo-with-one-20261121-0246

## Run it

`python3 main.py` writes /output/entry.png

Set `MAKEFUN_OUTPUT_DIR` to change the output directory. Requires Python 3 with Pillow; the drawing is deterministic, with no randomness and no network access.
